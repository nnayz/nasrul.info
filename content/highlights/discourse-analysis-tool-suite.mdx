Discourse analysis at Hamburg needed to work outside the notebook it was written in. Researchers were working with large text collections, and they needed a shared application rather than a series of one-off scripts.

I worked on that application as part of DATS at the University of Hamburg's Language Technology Lab. My work covered the React and TypeScript interface, FastAPI services, and the NLP preprocessing and analysis paths behind them. I was connecting the research code to the place where people would use it.

That changed what an experiment needed around it. The analysis had to fit behind a stable REST API, and the services had to run in Docker rather than only in their author's environment. Those parts were as much a part of my work as the interface.

It wasn't an unqualified improvement for every step. Some experiments moved more slowly when they had to fit into the shared platform. Collaboration and demos became easier, though, because the code no longer had to stay in a script that only its author could run.

The [suite is available on the university demo host](https://dats.ltdemos.informatik.uni-hamburg.de) for the Language Technology group.
